# SQL-песочница

Это ваша собственная копия базы данных **Nur Finance** — тех же 11 таблиц, которыми пользуются аналитики банка в этом курсе, со всеми строками. Делайте здесь что угодно:

- **Задавайте вопросы** с помощью `SELECT`, `WHERE`, `GROUP BY`, `JOIN`.
- **Создавайте** свои таблицы через `CREATE TABLE`, наполняйте через `INSERT`, исправляйте строки через `UPDATE`, удаляйте строки через `DELETE`, выбрасывайте таблицу через `DROP TABLE`.
- **Меняйте и таблицы компании** — попробуйте `UPDATE loans SET status = 'closed' WHERE loan_id = 1;` и посмотрите ещё раз.

Всё, что вы меняете, **сохраняется на этом устройстве** — закройте страницу, вернитесь завтра, ваши таблицы будут на месте. Изменили слишком много? Откройте панель «База данных» (**Database**, внизу справа) и нажмите **↺ Сбросить**, чтобы вернуть исходные данные. Проверки домашних заданий всегда используют исходные данные, поэтому ничто из сделанного здесь не может их испортить.

**Ориентируйтесь так:** панель «База данных» перечисляет все таблицы, их столбцы, какой столбец является ключом (PK) и куда указывает каждый внешний ключ (FK) — нажмите на FK, чтобы перейти к этой таблице. Нажмите на название, чтобы вставить его в запрос, **+ SELECT** — для готового запроса, **Show rows** — чтобы заглянуть в данные. Созданные вами таблицы появляются вверху в разделе *Your tables*.

## Идеи, что попробовать :id=ideas-to-try

1. Сделайте таблицу из ваших любимых кредитов: `CREATE TABLE my_loans (loan_id INTEGER PRIMARY KEY, why TEXT);`, затем добавьте через `INSERT` три кредита и соедините (`JOIN`) её с `loans`, чтобы увидеть их суммы.
2. Закройте кредит: `UPDATE loans SET status = 'closed', closed_at = '2026-10-01' WHERE loan_id = 5;` — затем посчитайте кредиты по статусам и увидите, как число изменилось.
3. Удалите все платежи одного кредита, затем посмотрите, что `installments` всё ещё говорит о нём. Именно поэтому настоящие базы данных защищают внешние ключи.
4. Закончили? **↺ Сбросить** в панели «База данных».

На работе вы делали бы то же самое в таком приложении, как DBeaver, DataGrip или SQL Server Management Studio — SQL там тот же.
