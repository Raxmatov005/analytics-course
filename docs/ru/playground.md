## Четыре команды — краткий справочник :id=the-four-commands-a-mini-reference

Четыре команды меняют данные — **CREATE**, **INSERT**, **UPDATE**, **DELETE**, — и ещё две меняют или удаляют таблицу целиком: **ALTER** и **DROP**. По одному выполняемому примеру на каждую, на маленькой собственной таблице `my_notes`. Выполняйте блоки по порядку. Полный урок, с ключами и ловушками, — [Неделя 1 · День 3](weeks/week-01/day-3.md).

### CREATE TABLE — создаём пустую таблицу :id=create-table-make-an-empty-table

**Что это.** **CREATE TABLE** создаёт новую пустую таблицу: её имя, затем каждый столбец с типом и правилами.

**Как пишется.**

```sql
CREATE TABLE my_notes (
    -- ключ: одно значение на строку, заполняется само
    note_id  INTEGER PRIMARY KEY,
    loan_id  INTEGER NOT NULL,  -- должно быть заполнено
    note     TEXT    NOT NULL
);
```

*✓ Готово — таблица создана*. В **«База данных» → «Ваши таблицы»** теперь есть `my_notes` с 0 строк.

**Когда применять.** Чтобы хранить свой список, журнал или результат.

**Ваша очередь.** Шаг 1 практикума ниже.

### INSERT — добавляем строки :id=insert-add-rows

**Что это.** **INSERT** добавляет новые строки. Перечислите столбцы, затем по одной скобке значений на строку, в том же порядке.

**Как пишется.**

```sql
INSERT INTO my_notes (loan_id, note)
VALUES (1, 'Called the customer'), (2, 'Paid early');
SELECT * FROM my_notes;
```

2 строки: заметки 1 и 2. `note_id` заполнился сам.

**Когда применять.** Чтобы заполнить таблицу вручную или из запроса через `INSERT INTO … SELECT …`.

**Ваша очередь.** Шаг 2 практикума ниже.

### UPDATE — меняем строки :id=update-change-rows

**Что это.** **UPDATE … SET … WHERE** меняет значения в существующих строках. `WHERE` решает, в каких; без него меняется каждая строка.

**Как пишется.**

```sql
UPDATE my_notes SET note = 'Called twice' WHERE note_id = 1;
SELECT * FROM my_notes;
```

В заметке 1 теперь *Called twice*; заметка 2 не тронута.

**Когда применять.** Чтобы исправить или дополнить строку. Сначала выполните `WHERE` как `SELECT`.

**Ваша очередь.** Шаг 3 практикума ниже.

### DELETE — удаляем строки :id=delete-remove-rows

**Что это.** **DELETE FROM … WHERE** удаляет строки целиком. Таблица остаётся.

**Как пишется.**

```sql
DELETE FROM my_notes WHERE note_id = 2;
SELECT * FROM my_notes;
```

Осталась 1 строка: заметка 1.

**Когда применять.** Чтобы убрать ошибочную или ненужную строку. Отмены нет.

**Ваша очередь.** Шаг 4 практикума ниже.

### ALTER TABLE — меняем столбцы :id=alter-table-change-the-columns

**Что это.** **ALTER TABLE** меняет форму таблицы, в которой уже есть строки: добавить, переименовать или удалить столбец, переименовать таблицу.

**Как пишется.**

```sql
ALTER TABLE my_notes ADD COLUMN created_on TEXT;
SELECT * FROM my_notes;
```

У заметки 1 появился четвёртый столбец, `created_on`, пустой (NULL), пока вы его не заполните.

**Когда применять.** Когда вашей таблице нужен ещё один факт.

**Ваша очередь.** После практикума, в редакторе вверху: добавьте в `my_branches` текстовый столбец `opened_on` и посмотрите на неё через `SELECT * FROM my_branches;`.

### DROP TABLE — удаляем таблицу целиком :id=drop-table-remove-the-whole-table

**Что это.** **DROP TABLE** удаляет таблицу со всеми строками и столбцами. `DELETE` опустошает таблицу; `DROP` заставляет её исчезнуть.

**Как пишется.**

```sql
DROP TABLE IF EXISTS my_notes;   -- IF EXISTS: без ошибки, если таблицы уже нет
```

*✓ Готово — таблица удалена*. `my_notes` пропала из **«Ваших таблиц»**.

**Когда применять.** Чтобы убрать ненужные таблицы.

> ⚠️ **Осторожно.** Ни одна команда здесь не спрашивает «вы уверены?». На этой странице **↺ Сбросить** вернёт исходные данные; на работе — только резервная копия.

**Ваша очередь.** Когда закончите практикум, удалите `my_branches` в редакторе вверху.

## Идеи, что попробовать :id=ideas-to-try

1. Сделайте таблицу из ваших любимых кредитов: `CREATE TABLE my_loans (loan_id INTEGER PRIMARY KEY, why TEXT);`, затем добавьте через `INSERT` три кредита и соедините (`JOIN`) её с `loans`, чтобы увидеть их суммы.
2. Закройте кредит: `UPDATE loans SET status = 'closed', closed_at = '2026-10-01' WHERE loan_id = 5;` — затем посчитайте кредиты по статусам и увидите, как число изменилось.
3. Удалите один кредит: `DELETE FROM loans WHERE loan_id = 5;`. Затем поищите его строки в `installments` и `payments` — они на месте и указывают на кредит, которого больше нет (*сироты*). База, которая следит за своими внешними ключами, отказалась бы выполнять такое удаление; SQLite следит за ними, только если они объявлены и включены (неделя 1 · день 3).
4. Закончили? **↺ Сбросить** в панели «База данных».

На работе вы делали бы то же самое в таком приложении, как DBeaver, DataGrip или SQL Server Management Studio — SQL там тот же.

## SQLite и SQL Server рядом :id=sqlite-and-sql-server-side-by-side

Этот сайт работает на SQLite, многие банки — на SQL Server. Почти весь SQL в них одинаков; здесь на одной карточке собраны места из недель 1–3, где он различается. Держите её открытой, когда переводите запрос.

| Нужно | SQLite (этот сайт) | SQL Server |
|---|---|---|
| первые N строк | `… ORDER BY x LIMIT 5` | `SELECT TOP 5 … ORDER BY x` |
| значение вместо NULL | `COALESCE(x, 0)` или `IFNULL(x, 0)` | `COALESCE(x, 0)` или `ISNULL(x, 0)` |
| склеить тексты | `a \|\| ' ' \|\| b` (NULL делает всё NULL) | `a + ' ' + b` (так же) или `CONCAT(a, ' ', b)` (NULL считается пустым) |
| длина текста | `LENGTH(s)` считает пробелы в конце | `LEN(s)` их не считает; `DATALENGTH(s)` считает |
| кусок текста | `SUBSTR(s, 1, 4)` | `SUBSTRING(s, 1, 4)`, `LEFT(s, 4)`, `RIGHT(s, 4)` |
| где начинается кусок | `INSTR(s, 'x')` | `CHARINDEX('x', s)` |
| «сегодня» | здесь никогда `date('now')`: пишите `'2026-10-01'` | `GETDATE()` — то же предупреждение |
| дни между двумя датами | `julianday(b) - julianday(a)` | `DATEDIFF(day, a, b)` — считает пересечённые границы |
| через месяц | `date(d, '+1 month')`: 31 янв → 3 мар | `DATEADD(month, 1, d)`: 31 янв → 28 фев |
| год и месяц даты | `strftime('%Y-%m', d)` — текст | `FORMAT(d, 'yyyy-MM')`, `YEAR(d)`, `MONTH(d)` |
| посчитать, где условие истинно | `SUM(status = 'x')` | `SUM(IIF(status = 'x', 1, 0))`; `SUM(CASE …)` работает в обоих |
| `7 / 2` | `3`: целое ÷ целое = целое | `3`, так же — пишите `7 * 1.0 / 2` |
| `10 / 0` | NULL, без ошибки | ошибка; `10 / NULLIF(0, 0)` даёт NULL в обоих |
| текст, который не число | `CAST('abc' AS INTEGER)` равно 0 | ошибка; `TRY_CAST` даёт NULL |
| `'card' = 'Card'` | ложь; `LIKE` не различает латинский регистр | обычно истина: сортировка (collation) не различает регистр |
| псевдоним в `GROUP BY` | можно | нельзя: повторите выражение |
| столбец не в группе и не в агрегате | выполняется и берёт какую-то строку | ошибка |
| рекурсивный CTE | `WITH RECURSIVE` | `WITH` (и `OPTION (MAXRECURSION n)` больше 100 уровней) |
| результат, сохранённый как таблица | `CREATE TABLE t AS SELECT …` | `SELECT … INTO t FROM …` |
| изменить представление | `DROP VIEW` + `CREATE VIEW` | `CREATE OR ALTER VIEW` |
| `SUM` большого целого столбца | без проблем | `INT` переполняется после примерно 2.1 млрд: `SUM(CAST(x AS BIGINT))` |
