**Карта шагов** — у каждого ручного инструмента со среды есть записанный эквивалент; контрольная требует правый столбец:

| Вы разведали это с помощью | Вы поставляете это как |
|---|---|

| «Текст по столбцам» для datetime | Split Column → By Delimiter или Changed Type → Date |
| `SUMIFS` по каждому платежу по графику над платежами | Group By (Sum, Min) + Merge Queries (Left Outer) |
| второй файл, вставленный под первый | Append Queries |
| «в понедельник я сделал это снова» | Refresh All |
