## Сегодня в 3 строках :id=today-in-3-lines

- **Сводная таблица (PivotTable)** — это `GROUP BY` мышью: перетаскивайте поля в Rows / Columns / Values / Filters; **Show Values As** даёт % от итога, % от родителя, нарастающий итог и разность без формулы; **группируйте** даты по месяцам и кварталам; **срезы** и **временные шкалы** — это выпадающие списки страницы.
- **Диаграммы**: столбчатая для категорий, линейчатая для рейтингов, линия для времени, комбинированная для двух показателей, с накоплением для состава; никаких круговых больше трёх секторов, никакого 3D, столбцы от нуля; **заголовок формулирует вывод**; спарклайны для тренда в ячейке.
- Вы построили страницу Мадины: четыре сводные таблицы, четыре диаграммы, шесть плиток, один срез — обновляемую, с каждым числом, сверенным с третьей неделей.

## 1. Изучение — сводная таблица — это GROUP BY, который можно перетащить :id=1-learn-the-pivot-is-group-by-you-can-drag

### Сводные таблицы (*сводные таблицы*) :id=pivottables-сводные-таблицы

Щёлкните внутри `tblLoans` → Вставка → **Сводная таблица** → На новый лист. Появляется список полей: перетащите `product` в **Rows**, `outstanding` в **Values** (станет *Sum of outstanding*), `loan_id` в **Values** (станет *Count of loan_id*). Это `SELECT product, SUM(outstanding), COUNT(*) FROM loans GROUP BY product`. Перетащите `bucket` в **Columns** для перекрёстной таблицы; `status` в **Filters** для `WHERE` на уровне страницы. Четыре области, одно правило: поле в Rows или Columns — это ключ `GROUP BY`; поле в Values — агрегат; поле в Filters — `WHERE`, который может менять читатель.

Google Sheets: выделите данные → Вставка → **Сводная таблица**; редактор справа содержит те же Rows / Columns / Values / Filters. Сводные таблицы Sheets не умеют группировать даты правой кнопкой — сначала добавьте в данные столбец `month` (`=EOMONTH(G2, -1)+1` или `TEXT`) или используйте `QUERY` с `month(G)`.

**Value Field Settings** (правый щелчок по значению → *Параметры поля значений*; Sheets: выпадающий список *Summarize by*): **Sum / Count / Average / Max / Min / Count Numbers / StdDev**. Затем вторая вкладка, **Show Values As** (Sheets: *Show as*):

| Show Values As | Что означает | На наших данных |
|---|---|---|
| % of Grand Total | доля от всей таблицы | остаток долга SME 60.3 % |
| % of Column Total / % of Row Total | доля внутри столбца / строки | внутри корзины 90+, какой продукт |
| **% of Parent Row Total** | доля внутри родительской группы строки (регион → филиал) | Tashkent Central 35.2 % от Tashkent |
| **Running Total In** (базовое поле) | накопление вниз по выбранному полю | выдачи 2026 года с начала года по месяцам |
| **Difference From** / **% Difference From** (previous) | изменение относительно предыдущего элемента | февраль −5 558 520 000, −31.8 % |
| Rank Largest to Smallest | оконная функция `RANK()` | филиалы 1–10 |

Это оконные функции третьей недели в виде выпадающего списка — `SUM(SUM(x)) OVER ()`, `OVER (PARTITION BY region)`, `OVER (ORDER BY month ROWS UNBOUNDED PRECEDING)`, `LAG`. Поместите одно и то же поле в Values дважды, чтобы показать число и его долю рядом.

**Группировка дат** (*группировка*): поместите `disbursed_at` в Rows → Excel 365 группирует его в Years / Quarters / Months автоматически; правый щелчок → **Group**, чтобы выбрать (Months + Years или Quarters). Ungroup возвращает дни. Группировка работает, только если каждое значение в столбце — настоящая дата: одна дата-текст, и команда Group становится серой — это вчерашний урок про `DATEVALUE`, проявившийся симптомом.

**Вычисляемые поля** (PivotTable Analyze → Fields, Items & Sets → **Calculated Field**; Sheets: Values → Add → *Calculated field*): новое значение, вычисляемое из *сумм* других полей, — `= outstanding * rate / 12` даёт месячный темп начисления процентов по продуктам (4 491 202 901 в сумме), `= paid / total_due` даёт уровень сбора по месяцам как **отношение сумм**, верно. Ловушка: вычисляемое поле вычисляется на *агрегированных* числах, поэтому `= principal / loans` работает, только если `loans` — это столбец из единиц, который вы добавили в данные, — внутри вычисляемого поля нет `COUNT`. И никогда не помещайте в Values *Average* от *ставки* по строкам, когда имеете в виду отношение итогов: среднее из 7 828 отдельных ставок взвешивает кредит Micro на 500 000 так же, как кредит SME на 599 млн.

**Срезы и временные шкалы** (*срезы*): PivotTable Analyze → Вставить **срез (Slicer)** → отметьте `product`, `region`: кнопки, фильтрующие сводную таблицу. Вставьте **временную шкалу (Timeline)** по `disbursed_at`: ползунок дат по месяцам / кварталам / годам. Правый щелчок по срезу → **Report Connections** → отметьте каждую сводную таблицу на странице, и один щелчок фильтрует их все — именно это делает страницу дашбордом. Sheets: один элемент *Filter* (Данные → Добавить срез) на лист, применяется ко всем сводным таблицам и диаграммам на нём.

**GETPIVOTDATA** (*ПОЛУЧИТЬ.ДАННЫЕ.СВОДНОЙ.ТАБЛИЦЫ*): щёлкните из формулы по ячейке сводной таблицы, и Excel напишет `=GETPIVOTDATA("outstanding", $A$3, "product", "Small business loan")` — поиск по сводной таблице по именам полей, переживающий пересортировку и перефильтрацию. Используйте её для **плиток**, которые должны читать то, что показывает сводная таблица; отключите (PivotTable Analyze → Options → *Generate GetPivotData*), когда нужна обычная ссылка `=B5`.

**Обновление и кэш.** Сводная таблица читает снимок (*кэш сводной таблицы*), сделанный при её создании; новые строки в `tblLoans` или обновление Power Query **не** появятся, пока вы не сделаете правый щелчок → **Refresh** (или Данные → Обновить все, что обновляет и запросы). Стройте на таблице или результате запроса, никогда на фиксированном диапазоне `A1:M7829` — диапазон не растёт. Сохраняйте форматы чисел: Value Field Settings → **Number Format** (`#,##0`, `0.0%`), а не ячейки, иначе формат исчезнет при обновлении. Design → Report Layout → **Tabular Form** и *Repeat All Item Labels*, если сводная таблица питает диаграмму или другую формулу.

**Оформление сводной таблицы для читателя** (восемь щелчков после перетаскивания):

1. Design → Report Layout → **Tabular Form**, *Repeat All Item Labels* — одно значение на столбец, без структуры с отступами.
2. Design → **Subtotals выключить**, **Grand Totals** включить только для столбцов (итог по строке из долей бессмыслен).
3. Value Field Settings → **Number Format** для каждого значения (`#,##0`, `0.0%`) — задавайте здесь, а не в ячейках.
4. **Переименуйте** заголовки значений на месте: *Sum of outstanding* → *Outstanding, UZS*.
5. **Отсортируйте** по главному значению по убыванию; перетащите элемент, чтобы переместить его (корзины, классы), когда порядок естественный.
6. PivotTable Options → Layout → **снимите Autofit column widths on update** — иначе каждое обновление сбрасывает ширину.
7. PivotTable Options → **For empty cells show** `0` — пустая ячейка в перекрёстной таблице читается как «неизвестно», 0 — как «нет».
8. **Закрепите** строку заголовка; сводная таблица из 34 месяцев прокручивается.

### Диаграммы (*диаграммы*) — какая и когда она врёт :id=charts-диаграммы-which-one-and-when-it-lies

Тип диаграммы определяется *вопросом*, а большинство неверных диаграмм — это неверный тип для верного числа:

| Вопрос | Диаграмма | Не |
|---|---|---|
| Как сравниваются категории? (остаток долга по продуктам) | **column** (мало коротких подписей) или **bar** (много длинных подписей; отсортирована по убыванию) | круговая — глаз не может сравнить секторы |
| Как что-то меняется во времени? (выдачи по месяцам) | **line** (34 месяца) или column (≤ 12 периодов) | столбчатая с месяцами как категориями без сортировки |
| Два показателя с разными единицами на одной временной шкале (количество и сумма) | **combo**: столбцы + линия на вторичной оси — подпишите обе оси | две линии на одной оси (количество сплющивается до нуля) |
| Как состоит итог по категориям? (корзины по продуктам) | **stacked column**; **100 % stacked**, когда структура важнее размера | пять круговых |
| Часть целого, 2–3 части | круговая или кольцевая *допустимы* | круговая с 5+ секторами, 3D-круговая (передний сектор выглядит больше), вырезанная круговая |
| Рейтинг (топ-5 филиалов) | горизонтальная **bar**, наибольшее сверху | столбчатая с повёрнутыми подписями |
| Тренд внутри строки таблицы | **sparkline** | диаграмма на каждую строку |

Правила, которые не вопрос вкуса: **столбцы и бары начинаются с нуля** (бар от 150 до 160 млрд делает рост на 7 % похожим на удвоение — усечённая ось допустима для линий, и даже тогда это нужно оговорить); **никакого 3D** (глубина ничего не добавляет и искажает); **сортируйте категории по значению**, если у них нет естественного порядка (месяцы, корзины); **один цвет** для ряда и **один цвет-акцент** для точки, о которой вы говорите (90+ красным); **подписывайте единицу оси** (млрд UZS, кредиты) или указывайте её в заголовке; **заголовок формулирует вывод** — *«SME — это 60 % книги на 10 % кредитов»*, а не *«Остаток долга по продуктам»*; подпись данных — это число, которое процитирует правление, так что отформатируйте её (`0.0` млрд). Легенда при одном ряде — провал подписывания; удалите её.

**Как построить**: выделите сводную таблицу (**PivotChart** остаётся связанной и подчиняется срезам) или обычный итоговый диапазон → Вставка → Рекомендуемые диаграммы → выберите → Chart Design → Add Chart Element (подписи данных, названия осей) → правый щелчок по оси → Format Axis (границы, формат числа `#,##0,,,` для миллиардов). **Спарклайны**: Вставка → Спарклайны → Line / Column / Win-Loss, диапазон данных = строка месяцев 2026, расположение = одна ячейка; отметьте *High point* и *Low point*; задайте одну и ту же вертикальную ось для всех строк (Sparkline → Axis → *Same for All Sparklines*), иначе 15 млрд у SME и 0.35 млрд у Micro выглядят одинаково. Sheets: Вставка → Диаграмма, с *Chart type*, *Customize → Chart & axis titles*; спарклайны — это функция, `=SPARKLINE(B2:K2, {"charttype","column"})`.

### Google Sheets: сводная таблица + диаграммы + QUERY :id=google-sheets-pivot-charts-query

Вставка → Сводная таблица (Rows / Columns / Values / Filters, *Show as* для % от общего итога / строки / столбца — нет % от родителя и нарастающего итога: добавьте вспомогательный столбец или используйте `QUERY`), *Calculated field* в Values, Данные → Добавить срез. Диаграммы: Вставка → Диаграмма, а *диаграмма* по сводной таблице — это просто диаграмма, диапазон которой — вывод сводной таблицы. **`QUERY`** — клавиатурная альтернатива, когда сводная таблица не справляется: `=QUERY(Loans!A1:M, "select D, sum(K), count(A) group by D order by sum(K) desc label sum(K) 'outstanding', count(A) 'loans'", 1)`; группировка дат через `month(G)+1` и `year(G)`; `pivot M` для перекрёстной таблицы; а результирующий диапазон питает диаграмму, как любой другой.

### SQL → сводная таблица, таблица соответствий :id=sql-pivot-the-translation-table

| SQL (недели 2–3) | Сводная таблица |
|---|---|
| `GROUP BY product` | `product` в **Rows** |
| `GROUP BY product, bucket` как перекрёстная таблица | `product` в Rows, `bucket` в **Columns** |
| `SUM(outstanding)`, `COUNT(*)`, `AVG(principal)`, `MAX(dpd)` | поле в **Values**, агрегат Sum / Count / Average / Max |
| `WHERE status = 'active'` (фиксированный) | `status` в **Filters** или срез |
| `WHERE disbursed_at >= … AND < …` | **временная шкала** по `disbursed_at` или Date Filters по полю строк |
| `100.0 * SUM(x) / SUM(SUM(x)) OVER ()` | Show Values As → **% of Grand Total** |
| `SUM(x) / SUM(SUM(x)) OVER (PARTITION BY region)` | **% of Parent Row Total** |
| `SUM(SUM(x)) OVER (ORDER BY month)` | **Running Total In** month |
| `SUM(x) - LAG(SUM(x)) OVER (ORDER BY month)` | **Difference From** previous |
| `RANK() OVER (ORDER BY SUM(x) DESC)` | **Rank Largest to Smallest**; сортировка по убыванию |
| `ORDER BY SUM(x) DESC LIMIT 5` | сортировка + Value Filter → **Top 10** → 5 |
| `strftime('%Y-%m', d)` в `GROUP BY` | правый щелчок по полю даты → **Group** → Months, Years |
| `SUM(a) / SUM(b)` | **вычисляемое поле** `= a / b` |
| `HAVING COUNT(*) > 100` | Value Filter → Greater Than по количеству |
| `CREATE VIEW`, из которого читает дашборд | сводная таблица на **таблице / запросе**, обновляемая |

Чего сводная таблица не умеет, а SQL умеет: `JOIN` (сначала слейте в Power Query или добавьте в данные столбец поиска), окно по *строкам*, а не по группам (`ROW_NUMBER` по кредиту), `COUNT(DISTINCT)` без модели данных (отметьте *Add this data to the Data Model* при создании сводной таблицы, тогда появится *Distinct Count* — способ посчитать заёмщиков по `Applications.customer_id`).

### Анатомия честной диаграммы :id=the-anatomy-of-an-honest-chart

1. **Заголовок = вывод**, словами читателя, с числом: *SME — это 60 % книги на 10 % кредитов.*
2. **Подзаголовок = определение и дата отсчёта**: *остаток основного долга, млрд UZS, на 1 окт 2026.*
3. **Ось от нуля** для баров и столбцов; усечённая ось линии так и подписана.
4. **Единицы** на оси или в подзаголовке; подписи данных отформатированы (`125.9`, а не `125892942411`).
5. **Отсортировано** по значению, если порядок не естественный (время, корзины, классы).
6. **Один цвет** для ряда, **один акцент** для точки, о которой заголовок, красный зарезервирован для *плохого*.
7. **Без легенды** при одном ряде; легенда для столбцов с накоплением, в порядке стека.
8. **Без 3D, градиентов, теней и ненужных линий сетки.**
9. **Неполные периоды** (октябрь) исключены или помечены.
10. **Строка источника** под диаграммой: *tblLoans · 7 828 кредитов · Nur Finance.*

### Excel ↔ Google Sheets, сегодняшние инструменты :id=excel-google-sheets-todays-tools

| Excel | Sheets | Примечание |
|---|---|---|
| Вставка → Сводная таблица | Вставка → Сводная таблица | те же четыре области |
| Value Field Settings → Show Values As | Values → *Show as* (% от общего итога / строки / столбца) | нет % от родителя, нарастающего итога и разности — вспомогательный столбец или `QUERY` |
| правый щелчок по дате → Group → Months | добавьте в данные столбец с месяцем (`=EOMONTH(G2,-1)+1`) | или `QUERY … group by year(G), month(G)` |
| Calculated Field | Values → Add → Calculated field | то же поведение «отношение сумм» |
| Срез, временная шкала, Report Connections | Данные → Добавить срез (применяется к листу) | один срез фильтрует каждую сводную таблицу и диаграмму на листе |
| `GETPIVOTDATA` | `GETPIVOTDATA` | те же аргументы |
| Refresh / Refresh All | автоматически (сводная таблица следует за исходным диапазоном) | расширьте исходный диапазон до целых столбцов |
| PivotChart | Вставка → Диаграмма по диапазону сводной таблицы | сама по себе не связана со срезами; срез листа делает это |
| Trendline → Moving Average | Customize → Series → Trendline → Moving average | |
| Вставка → Спарклайны | `=SPARKLINE(range, {"charttype","column"})` | функция, поэтому заполняется вместе со строкой |

### Ошибки, которые стоят балла на этой неделе :id=mistakes-that-cost-a-point-this-week

- Сводная таблица на фиксированном диапазоне — новые строки никогда не приходят; стройте на таблице или запросе.
- Забыли **Refresh** после обновления Power Query — сводная таблица показывает кэш прошлой недели.
- *Average* в Values, когда в предложении говорится «ставка» или «доля», — отношение сумм требует вычисляемого поля или двух сумм и формулы.
- Круговая с пятью продуктами (два сектора по 0.5 % невидимы) или 3D-столбчатая диаграмма.
- Ось бара, начинающаяся со 150 млрд.
- Заголовок диаграммы, называющий диаграмму (*Остаток долга по продуктам*), а не вывод.
- Однодневный столбец октября в месячном ряду без пометки.
- Два несвязанных показателя на двойной оси, из-за чего линии драматично пересекаются, — пересечение ничего не значит.
- Страница, оставленная отфильтрованной срезом, без видимой сверки с итогом таблицы.

Показ корзины 0 сделал бы стопку высотой 7 429, а остальное невидимым. 4. **Топ-5 филиалов — горизонтальная bar.** Рейтинг; наибольший сверху; остальные пять филиалов суммированы как *Others*, чтобы столбцы в сумме давали книгу. Заголовок: *Три ташкентских филиала, Fergana и Samarkand держат 63 % остатка долга.*
