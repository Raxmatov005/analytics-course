### Аудитория и одно решение :id=the-audience-and-the-one-decision

**Что это.** **Аудитория** — это те, кто будет вас читать или слушать, и то, за что отвечает каждый из них. **Одно решение** — это то, что встреча должна решить, когда вы замолчите. Каждый слайд либо служит этому решению, либо уходит в приложение.

**Как пишется.** По одной строке на каждого человека в комнате — до любого слайда:

| Кто | Отвечает за | Будет искать | Его число |
|---|---|---|---|
| CEO | весь план | решение и чего оно стоит | — |
| Бекзод | портфель, лимиты продуктов | рост и свои продукты | остаток долга |
| Нилуфар | политика рисков | число, которое можно атаковать | доля одобрений, FPD |
| Севара | взыскание | понимаете ли вы её команду | действия в сентябре |
| Камола | приложение | воронку | сессии приложения, дошедшие до денег |

```sql

       (SELECT ROUND(100.0 * SUM(CASE WHEN status IN ('approved', 'approved_not_disbursed') THEN 1 ELSE 0 END)
               / SUM(CASE WHEN status <> 'cancelled' THEN 1 ELSE 0 END), 1)
          -- Нилуфар
          FROM applications WHERE applied_at >= '2026-01-01' AND applied_at < '2026-10-01') AS approval_2026_pct,

         -- Севара

       (SELECT ROUND(100.0 * COUNT(l.loan_id) / COUNT(*), 1)
          FROM (SELECT DISTINCT application_id FROM app_events) s
          LEFT JOIN loans l ON l.application_id = s.application_id)                       AS app_to_money_pct;
```


### Главная мысль — принцип пирамиды :id=the-governing-thought-the-pyramid-principle

**Что это.** **Главная мысль** (*governing thought*) — одно предложение, которое отвечает на заданный вам вопрос. **Принцип пирамиды** ставит её наверх, под ней — причины, под каждой причиной — доказательства: читатель сначала получает ответ и останавливается, когда поверил вам.

**Как пишется.**

```text
                   главная мысль
   «Растить X и Y, притормозить Z, пока …, изменить A — стоит около N»
          /                  |                  \
     ключевая строка 1   ключевая строка 2   ключевая строка 3 ← причины, по одному предложению
     доказательства      доказательства      доказательства    ← по одному графику + одной таблице
```

На итоговом проекте: *«Растить филиальное кредитование и повторные кредиты в приложении, притормозить BNPL и самый рискованный регион, пока мы в них не разберёмся, и перенести усилия взыскания на первый месяц просрочки.»* Она называет продукты, регион и процесс, и каждую её часть можно сверить с числом.

**Когда применять.**
- Первый слайд после титульного и первое предложение, которое вы произносите.
- Как тест: если вы не можете её написать, ответа у вас ещё нет — вернитесь к дереву проблем.

> ⚠️ **Осторожно.** «Мы проанализировали портфель с пяти сторон» — это повестка, а не главная мысль. Она ни на что не отвечает.

### Сюжет — от трёх до пяти ключевых строк-предложений :id=the-storyline-three-to-five-key-lines-that-are-sentences

**Что это.** **Сюжет** — это от трёх до пяти **ключевых строк** под главной мыслью, то есть причины. Каждая — полное предложение с числом и сравнением. Если прочитать их по порядку, они выстраивают аргумент без единого графика.

**Как пишется.**

```text
ключевая строка = что + число + сравнение + и что из этого

1. Деньги    «На 1 000 выданных сум больше всех зарабатывают Auto (73) и SME (60); BNPL теряет 108.»
2. Риск      «Наш самый быстрорастущий регион, Нукус (+90 %), несёт самый высокий PAR30, 6.8 %.»
3. Процесс   «В сентябре связались лишь с 13 из 124 кредитов с ранней просрочкой; почти все усилия ушли на уже потерянные кредиты.»

```

Три ключевые строки соответствуют трём частям главной мысли: что растить, что притормозить, что изменить.

**Когда применять.**
- Чтобы выбрать слайды: каждая ключевая строка становится одним-двумя слайдами с выводами.
- Чтобы проверить логику: если ключевая строка не поддерживает главную мысль, одна из них неверна.

### Выбор графика — повторение :id=choosing-the-chart-a-recap

**Что это.** График следует за **типом сообщения**: изменение во времени, сравнение, часть целого, две меры на категорию, воронка, когорты, мост, одно число. Это правила графиков недели 5, применённые к презентации.

**Как пишется.** Сообщение слайда 6 — *«самый быстрорастущий регион несёт самый высокий риск»* — это две меры на категорию, поэтому нужна диаграмма рассеяния с подписанными точками:

```python
import matplotlib.pyplot as plt

regions = ["Nukus", "Namangan", "Bukhara", "Andijan", "Samarkand", "Tashkent", "Fergana", "Termez"]
# выдано янв.–сен. 2026 к 2025, %  (P7)
growth  = [89.7, 83.4, 76.4, 61.2, 58.6, 38.3, 26.1, -9.1]
# PAR30 на 2026-10-01, % остатка долга
par30   = [6.8, 1.7, 4.8, 4.0, 3.0, 3.4, 0.7, 0.7]

# один цвет для главной точки, серый для фона
colours = ["#c0392b" if r == "Nukus" else "#9aa0a6" for r in regions]
plt.scatter(growth, par30, c=colours, s=60)
for r, x, y in zip(regions, growth, par30):
    plt.annotate(r, (x, y), textcoords="offset points", xytext=(5, 4), fontsize=8)
plt.xlabel("disbursement growth, Jan–Sep 2026 vs 2025 (%)")
plt.ylabel("PAR30 (%)")
plt.title("The fastest-growing region carries the highest risk")
plt.show()
```

Нукус стоит один в правом верхнем углу: рост +89.7 % и PAR30 6.8 %. Наманган, растущий почти так же быстро (+83.4 %), — на 1.7 %: это контрпример, который сохраняет слайд честным.

**Когда применять.**

| Сообщение | График |
|---|---|
| изменение во времени | линия (столбцы, если периодов немного) |
| сравнение категорий | горизонтальные столбцы, отсортированные |
| две меры на категорию | диаграмма рассеяния с подписанными точками |
| воронка | горизонтальные столбцы с конверсией шага |
| когорты / поколения | линии, обрывающиеся там, где месяцы не наблюдаются |
| что объясняет изменение | водопад |
| одно число | большое число + сравнение |

> ⚠️ **Осторожно.** Линия с двумя осями придумывает пересечения; линия поколения, продолжающаяся в ненаблюдаемые месяцы, падает до 0 и выглядит как улучшение. Если графику нужно предложение о том, как его читать, — смените график.

### Макет дашборда — правило левого верхнего угла, один вопрос на плитку :id=dashboard-layout-the-top-left-rule-one-question-per-tile

**Что это.** Страницу дашборда читают как страницу текста: сначала левый верхний угол, затем вправо, затем вниз. **Правило левого верхнего угла**: самое важное число стоит слева вверху. **Один вопрос на плитку**: каждая карточка, график или таблица отвечает ровно на один вопрос, который можно написать над ней.

**Как пишется.** Нарисуйте страницу прямоугольниками, у каждого — свой вопрос, до того как что-либо строить:

```text
┌───────────────┬───────────────┬───────────────┬───────────────┐
│ Остаток долга │ Выдано        │ Рост к        │ Средний       │   ← карточки: «сколько?», «как быстро?»
│ 208.7 млрд    │ янв.–сен. 2026│ янв.–сен. 2025│ чек           │
├───────────────┴───────────────┼───────────────┴───────────────┤
│ Выдачи по месяцам, 2025 против│ Выдачи по продуктам,          │   ← «когда?» и «что?»
│ 2026 (линия)                  │ отсортированы, с ростом в %   │
├───────────────────────────────┼───────────────────────────────┤
│ Таблица регионов: выдано,     │ Структура: доля каждого       │   ← «где?» и «какая структура?»
│ рост %, PAR30                 │ продукта                      │
└───────────────────────────────┴───────────────────────────────┘
  срезы: продукт · канал · регион · период        на 2026-10-01 · определения в подсказках
```

Четыре карточки верхнего ряда — из одного запроса:

```sql
SELECT (SELECT SUM(principal_due) FROM installments WHERE due_date > '2026-10-01')        AS outstanding,
       SUM(CASE WHEN disbursed_at >= '2026-01-01' AND disbursed_at < '2026-10-01' THEN principal ELSE 0 END) AS disbursed_2026,
       ROUND(100.0 * SUM(CASE WHEN disbursed_at >= '2026-01-01' AND disbursed_at < '2026-10-01' THEN principal ELSE 0 END)
             / SUM(CASE WHEN disbursed_at >= '2025-01-01' AND disbursed_at < '2025-10-01' THEN principal ELSE 0 END) - 100, 1) AS growth_pct
FROM loans;
```

Остаток долга 208 723 504 430 сум — слева вверху; в январе–сентябре 2026 выдано 161 480 300 000, +45.6 % к тем же месяцам 2025. Четвёртая карточка, средний чек, — это P6.

**Когда применять.**
- До того как открыть Power BI или Excel: набросок и есть техническое задание.
- Когда страница кажется перегруженной: любая плитка, вопрос которой вы не можете написать, уходит.

> ⚠️ **Осторожно.** Двенадцать визуалов на одной странице — это двенадцать вопросов и ни одного ответа. Шесть–восемь плиток — это страница; больше — это две страницы.

### Аннотация — числа, которые произносят вслух :id=annotation-numbers-that-are-read-aloud

**Что это.** **Аннотация** — текст на графике, который говорит главное: важное число, подписанное там, куда уже смотрит глаз. Числа на слайдах **округляют до того, что можно произнести вслух**, — «208.7 млрд», а не 208 723 504 430 — с единицей и сравнением.

```pic
{"id": "w08d4-pic1", "title": "Округляйте до того, что можно сказать вслух, — не меняя смысла", "caption": "Двенадцать цифр превращаются в три, с единицей. Последняя строка сохраняет разницу: «1.7 против 1.0», а не «около 1 % у обоих».", "tables": [{"name": "say()", "cols": ["exact", "said aloud"], "new": ["said aloud"], "rows": [["208 723 504 430", "208.7 млрд сумов"], ["161 480 300 000", "161.5 млрд сумов"], ["3.1178 %", "PAR30 3.1 %"], ["1.70 % vs 1.04 %", "1.7 против 1.0"]]}]}
```

**Как пишется.**

```python
def say(x, unit="soum"):
    """Round a number the way you would say it in a meeting."""
    for size, word in [(1e12, "trn"), (1e9, "bn"), (1e6, "m"), (1e3, "k")]:
        if abs(x) >= size:
            return f"{x / size:.1f} {word} {unit}"
    return f"{x:.0f} {unit}"

print(say(208_723_504_430))                 # книга
```
