## 1. Теория — логика теста :id=1-learn--the-logic-of-a-test

### H₀, H₁ и зал суда :id=h₀-h₁-and-the-courtroom

**Проверка статистических гипотез** (*hypothesis test*) начинается с **нулевой гипотезы** H₀ (*null hypothesis*) — «ничего не происходит»: p_app = p_branch. **Альтернативная гипотеза** H₁ (*alternative hypothesis*) — то, что вы заключили бы в противном случае: p_app ≠ p_branch. Вы вычисляете **статистику критерия** (*test statistic*), которая измеряет, насколько данные далеки от H₀ в единицах шума, и спрашиваете, насколько необычным было бы это значение, **если бы H₀ была верна**. Если очень необычным, вы **отвергаете H₀**; иначе **не отвергаете** её. Это суд: H₀ — «невиновна», данные — доказательства, а «не виновна» означает «не доказана», но никогда «доказана невиновность».

### p-значение — одно верное определение, три неверных :id=the-p-value--one-right-definition-three-wrong-ones

**p-значение** (*p-value*): *вероятность, вычисленная в предположении, что H₀ верна, получить статистику критерия не менее экстремальную, чем наблюдаемая.* Для приложения против филиалов: если бы у обоих каналов была одинаковая истинная ставка FPD, разрыв в 0.66 пункта или больше (в любую сторону) появлялся бы в **3.2 %** выборок такого размера.

Чем оно **не** является:

1. **Не** «вероятность того, что H₀ верна» (шанс 3.2 %, что каналы равны). p-значение вычисляется *в предположении* H₀; оно не может одновременно быть её вероятностью.
2. **Не** «вероятность того, что результат вызван случайностью». Та же ошибка, более дружелюбными словами.
3. **Не** мера размера или важности эффекта. p = 0.0001 может получиться из тривиального разрыва, измеренного на миллионе строк (P10).

И p > 0.05 — это **не** «доказательство отсутствия различий», а «данные не исключают отсутствие различий», что при малом n — слабое утверждение.

### α, две ошибки, мощность :id=α-the-two-errors-power

Заранее, до просмотра данных, выберите **уровень значимости** α (*significance level*) — вероятность ошибки I рода, которую вы готовы принять; по соглашению это 5 %. Отвергайте H₀, когда p < α.

| | H₀ верна (реальной разницы нет) | H₀ неверна (реальная разница есть) |
|---|---|---|
| отвергаем H₀ | **ошибка I рода** (*type I error*), вероятность α — «приложение хуже», когда это не так: маркетинг теряет хороший канал | верно — вероятность = **мощность** (*power*) = 1 − β |
| не отвергаем | верно | **ошибка II рода** (*type II error*), вероятность β — реальное ухудшение, пропущенное на год |

Снижение α до 1 % даёт меньше ложных тревог ценой большего числа пропусков. Уменьшить обе ошибки может только больше данных — сколько именно, решит расчёт мощности в четверг.

### Одно- или двусторонний :id=one--or-two-sided

**Двусторонний** критерий (*two-sided*) спрашивает «отличается в любую сторону»; **односторонний** (*one-sided*) спрашивает только «выше» и вдвое уменьшает p-значение: приложение против филиалов двусторонний **0.0318**, односторонний 0.0159. Используйте односторонний, только если результат в другую сторону привёл бы к тому же действию, что и «нет различий», **и** вы записали это до просмотра данных. Комитет по рискам действует в обоих направлениях (заметно *лучший* канал приложения тоже изменил бы политику), поэтому по умолчанию — двусторонний.

### z-критерий для двух долей :id=z-test-for-two-proportions

```
pooled p = (k₁ + k₂) / (n₁ + n₂)            SE = √( p(1 − p) (1/n₁ + 1/n₂) )            z = (p̂₁ − p̂₂) / SE
app vs branch: pooled = 75 / 5 674 = 1.322 %;  SE = 0.307 points;  z = (1.700 − 1.042) / 0.307 = 2.147;  p = 2·(1 − Φ(2.147)) = 0.0318
```

```python
from statsmodels.stats.proportion import proportions_ztest, confint_proportions_2indep
proportions_ztest([41, 34], [2411, 3263])                                  # (2.147, 0.0318)
confint_proportions_2indep(41, 2411, 34, 3263, method="newcomb")           # difference: +0.05 to +1.33 points
```

**Как выглядит p = 0.032.** Смоделируйте H₀ напрямую: дайте обоим каналам объединённую ставку 1.322 %, разыграйте 100 000 пар выборок по 2 411 и 3 263 кредитов и посчитайте, как часто разрыв составляет не меньше 0.66 пункта в любую сторону.

```python
rng = np.random.default_rng(2026)
p0 = 75 / 5674
diff = rng.binomial(2411, p0, 100_000) / 2411 - rng.binomial(3263, p0, 100_000) / 3263
np.mean(np.abs(diff) >= 41/2411 - 34/3263)          # 0.0321 — the z-test's 0.0318, by brute force
np.quantile(diff, [0.025, 0.975])                   # ±0.60 points: the gap chance alone produces 95 % of the time
```

Вот и всё, что такое p-значение: доля мира H₀, которая выглядит по меньшей мере так же экстремально, как наш. Формула z — это сокращённый путь; симуляция — это определение.

В Excel — одна строка на канал и четыре ячейки с формулами:

| | A | B | C |
|---|---|---|---|
| 1 | | FPD | n |
| 2 | app | 41 | 2411 |
| 3 | branch | 34 | 3263 |
| 5 | pooled | `=(B2+B3)/(C2+C3)` → 0.01322 | |
| 6 | SE | `=SQRT(B5*(1-B5)*(1/C2+1/C3))` → 0.00307 | |
| 7 | z | `=(B2/C2-B3/C3)/B6` → 2.147 | |
| 8 | p (two-sided) | `=2*(1-NORM.S.DIST(ABS(B7),TRUE))` → 0.0318 | |

95-процентный интервал **разности** не включает 0, что равносильно вердикту p < 0.05. Вчера два интервала Уилсона пересекались (1.26–1.45 %) — а разница всё равно значима: SE разности равна √(SE₁² + SE₂²) = 0.318 пункта, меньше, чем SE₁ + SE₂ = 0.441. Пересечение двух 95-процентных интервалов — куда более строгое правило, чем 5-процентный тест; никогда не проверяйте гипотезы на глаз.

### Критерий хи-квадрат на независимость :id=chi-square-test-of-independence

**Критерий хи-квадрат Пирсона** (*chi-square test*) сравнивает таблицу сопряжённости с количествами, ожидаемыми при независимости двух переменных: ожидаемое = итог строки × итог столбца / общий итог; χ² = Σ (наблюдаемое − ожидаемое)² / ожидаемое, с (строки − 1)(столбцы − 1) степенями свободы.

```python
ct = pd.crosstab(f["channel"], f["fpd30"])        # app 2370/41 · branch 3229/34 · partner 1409/16
chi2, p, dof, expected = stats.chi2_contingency(ct)                 # chi2 = 5.108, dof = 2, p = 0.0778
```

| канал | наблюдаемые FPD | ожидаемые FPD | наблюдаемые не-FPD | ожидаемые не-FPD | (O − E)² / E, ячейка FPD |
|---|---|---|---|---|---|
| app | 41 | 30.9 | 2 370 | 2 380.1 | 3.30 |
| branch | 34 | 41.8 | 3 229 | 3 221.2 | 1.46 |
| partner | 16 | 18.3 | 1 409 | 1 406.7 | 0.28 |

**FPD × канал, все три канала: p = 0.078 — не значимо при 5 %.** Ожидаемые FPD при независимости — 30.9 / 41.8 / 18.3; 41 у приложения — единственная ячейка, далёкая от ожидаемой, и распределённая на две степени свободы она недостаточна. Это не противоречит z-критерию: χ² отвечает на вопрос «различаются ли три канала вообще?», z-критерий — на более узкий вопрос, выбранный после просмотра таблицы (приложение против филиалов — два крайних). На таблице 2 × 2 χ² *и есть* z-критерий: без поправки на непрерывность χ² = 4.610 = 2.147², p = 0.0318 совпадает; с поправкой Йейтса (умолчание scipy на 2 × 2) p = 0.042. Excel: `=CHISQ.TEST(observed_range, expected_range)`. Практическое правило: все ожидаемые количества ≥ 5 (иначе — Фишер, завтра).

**Просрочка платежа × грейд** (52 850 чистых платежей; просрочка = оплачено после даты платежа): A 5.09 % · B 9.82 % · C 19.62 % · D 35.60 %; χ² = 2 595, df 3, p ≈ 0; **V Крамера** = √(χ² / (n · (min(r, c) − 1))) = **0.22**, умеренная связь. Одна честная оговорка: критерий предполагает независимость строк, а один кредит даёт в среднем 7.1 платежа — платежи одного кредита не независимы. Перезапуск на уровне **кредитов** (доля кредитов с любой просрочкой: A 29.6 · B 46.5 · C 69.0 · D 85.6 %): χ² = 771, p ≈ 10⁻¹⁶⁷. Тот же вердикт, честная единица анализа.

### t-критерий и критерий Уэлча — сравнение средних :id=t-test-and-welch--comparing-means

**Двухвыборочный t-критерий** (*t-критерий Стьюдента*) сравнивает два средних: t = (x̄₁ − x̄₂) / SE. Версия Стьюдента предполагает равные дисперсии; **критерий Уэлча** (*Welch's*) — нет, и почти ничего не теряет, когда они равны, — используйте Уэлча по умолчанию (`equal_var=False`; Excel `=T.TEST(r1, r2, 2, 3)`, где 2 = двусторонний, 3 = неравные дисперсии).

- **Кредитные скоры заявителей, приложение против филиалов**: 661.0 против 659.6, t Уэлча = 1.23, **p = 0.218** — нет свидетельств, что приложение привлекает других заявителей. Левен p = 0.77 (равные дисперсии), Шапиро на 500 заявителях из приложения p = 0.70.
- **Скоры одобренных кредитов, приложение против филиалов**: 683.2 против 679.8, t = 2.48, **p = 0.013** — значимо, но это 3.4 пункта на шкале с sd 52: d Коэна = 0.06, ничто.
- **Ловушка: основной долг по каналам.** t Уэлча = −43.3, p ≈ 0. Бессмысленно: `pd.crosstab(loans.channel, loans.code)` показывает, что приложение = только Micro, партнёры = только BNPL, филиалы = Auto + Consumer + SME. Канал и продукт **смешаны** (*confounded*); никакой тест их не разделит. Разрыв FPD у Нилуфар — неизбежно ещё и разрыв между *Micro через приложение* и *другими продуктами через филиалы* — в записке об этом надо сказать.

### Связанные и независимые выборки :id=paired-vs-independent-samples

**Связанные** (*зависимые*, *paired*) выборки означают, что у каждого значения в одной группе есть пара в другой — тот же филиал в два года, тот же клиент до и после. Парный тест работает с **разностями** и убирает вариацию между единицами. FPD30 тех же десяти филиалов, поколения 2025 против поколений 2026:

```python
w = f[f.year.isin([2025, 2026])].pivot_table(index="branch_name", columns="year", values="fpd30", aggfunc="mean") * 100
stats.ttest_rel(w[2026], w[2025])        # t = -2.56, p = 0.031   (mean change -0.58 points)
stats.ttest_ind(w[2026], w[2025])        # t = -2.05, p = 0.055   — the wrong test throws away the pairing
```

Девять из десяти филиалов улучшились; Tashkent North вырос с 0.55 до 1.54 %. Парность превратила «пограничное» в «значимое», потому что филиал с высокой ставкой в 2025 году склонен оставаться высоким. Excel: `=T.TEST(r2025, r2026, 2, 1)` (тип 1 = парный).

### Проверка допущений — нормальность чего? :id=checking-assumptions--normality-of-what

t-критерию нужно, чтобы **выборочное распределение среднего** было нормальным, а не данные (квиз оригинального курса: *нормальность статистики, например среднего*). При n в сотнях ЦПТ обеспечивает это даже для асимметричных данных; при n = 10 и асимметричных деньгах — нет. Инструменты: **QQ-график** (всегда), **Шапиро–Уилк** `stats.shapiro` (*критерий Шапиро–Уилка*) на выборке в несколько сотен — на тысячах строк он отвергает отклонения, которые никого не волнуют (500 основных долгов из приложения: p = 1.2 × 10⁻¹², потому что чеки Micro распределены равномерно между лимитами продукта круглыми десятками тысяч, а t-критерий на 2 669 из них всё равно в порядке), **Левен** `stats.levene` для равенства дисперсий (или пропустите его и используйте Уэлча). Когда допущения нарушены при малом n — непараметрические тесты завтра.

```python
la = loans.loc[loans.channel == "app", "principal"]
stats.probplot(la, dist="norm", plot=plt)                         # the picture first: an S with steps, not a line (flat, round tickets)
stats.shapiro(la.sample(500, random_state=2026))                  # p = 1.2e-12: not normal — and with n = 2 669 the CLT does not care
stats.levene(sa, sb)                                              # p = 0.77: equal variances (Welch would not have needed it)
stats.skew(la), len(la)                                           # 0.03, 2 669 — symmetric and many: the mean's interval is safe
```

Правило решения, которым вы будете пользоваться: **n велико (сотни на группу) → t / Уэлч подходит для средних, что бы ни сказал Шапиро; n мало, а QQ-график изогнут или есть несколько огромных значений → Манна–Уитни или перестановочный тест (День 4); вопрос о медиане или «типичном» значении → вообще не t-критерий.**

### Размер эффекта — значимость не есть важность :id=effect-size--significance-is-not-importance

p-значение говорит, можно ли увидеть эффект; **размер эффекта** (*effect size*) говорит, важен ли он. Для долей: **разность** (приложение − филиалы = **+0.66 пункта**, 95 % CI от +0.05 до +1.33), **относительный риск** (1.70 / 1.04 = **1.63**, CI 1.04–2.56) и бизнес-единица — **дополнительные FPD на 1 000 кредитов: 6.6** (CI 0.5–13.3). Для средних: **d Коэна** = разность / объединённое sd (0.2 малый, 0.5 средний, 0.8 большой). Одно и то же p-значение может стоять и на огромном, и на тривиальном эффекте; какой именно — решает n.

### Как читать результат и как его записывать :id=reading-a-result-writing-a-result

Каждый тест scipy / statsmodels возвращает две одинаковые вещи — статистику и p-значение (иногда df, иногда интервал):

```python
r = stats.ttest_ind(sa, sb, equal_var=False)
r.statistic, r.pvalue, r.df          # 1.233, 0.218, 10 451 — Welch's df is fractional, that is normal
r.confidence_interval()              # the interval of the difference in means: report it too
```

Затем одно предложение из шести частей, в таком порядке — это предложение, которое хотят видеть и экзаменатор, и комитет: *«[Группа A] имела [оценку] против [оценки] для [группы B] (разность [d], 95 % CI [lo, hi]); [названный критерий] даёт [статистика] = [значение], p = [значение]; [вывод при заранее выбранном α], [эффект в бизнес-единицах]».* Например: *«У кредитов из приложения FPD30 1.70 % против 1.04 % у кредитов из филиалов (разность +0.66 пункта, 95 % CI от +0.05 до +1.33); двусторонний z-критерий для двух долей даёт z = 2.15, p = 0.032; при α = 5 % ставка приложения выше, около 7 дополнительных FPD на 1 000 кредитов».* Округляйте p до двух значащих цифр (0.032, 0.00008), никогда не пишите «p = 0.000»; пишите «p < 0.001», когда оно столь мало.

**1. Вопрос и гипотезы.** Отличается ли вероятность FPD30 у канала приложения от филиалов? H₀: p_app = p_branch; H₁: ≠ (двусторонняя); α = 0.05, фиксируется сейчас.

**2. Данные.** 41 / 2 411 против 34 / 3 263 (FPD30 с 5-й недели, платежи без дублей, первая дата платежа ≤ дата отчёта − 30 дней).

**3. Тест.** Две независимые доли, 34–41 событие в группе (ожидаемые количества намного выше 5): z-критерий для двух долей. **z = 2.147, p = 0.032.** Точный критерий Фишера (завтра) согласен: p = 0.034.

```python
k, n = np.array([41, 34]), np.array([2411, 3263])
z, p = proportions_ztest(k, n)                                                    # 2.147, 0.0318
lo, hi = confint_proportions_2indep(41, 2411, 34, 3263, method="newcomb")          # +0.0005, +0.0133
rr_lo, rr_hi = confint_proportions_2indep(41, 2411, 34, 3263, compare="ratio", method="log")   # 1.04, 2.56
stats.fisher_exact([[41, 2370], [34, 3229]])                                       # odds ratio 1.64, p = 0.0344
stats.chi2_contingency(pd.crosstab(f.channel, f.fpd30))[1]                         # 0.0778 — the three-channel check
```

**4. Размер.** +0.66 пункта (95 % CI от +0.05 до +1.33); RR 1.63 (1.04–2.56); **6.6 дополнительных FPD на 1 000 кредитов из приложения**. При темпе 2026 года (1 036 кредитов из приложения за январь–сентябрь, ~1 381 в год) это ~9 дополнительных FPD в год по кредитам в среднем 2.69 млн: ~25 млн сумов экспозиции, ~15 млн ожидаемых потерь при LGD 60 %.

**5. Оговорки, которые попадают в записку.** (а) Трёхканальный χ² не значим (p = 0.078), а приложение против филиалов выбрано как самая экстремальная пара — доказательства **умеренные**, не подавляющие. (б) Все кредиты из приложения — Micro, кредиты филиалов — Auto / Consumer / SME: разрыв — это канал *и* продукт; данные не могут их разделить. (в) Интервал разности начинается с +0.05 пункта — совместим почти с ничем.

### Типичные ошибки :id=mistakes-people-make

- «p = 0.032 означает шанс 3.2 %, что приложение и филиалы одинаковы».
- «p = 0.078, значит, FPD не зависит от канала» — отсутствие доказательств, малое n.
- Переход на односторонний тест после того, как увидели направление; выбор пары для теста после просмотра таблицы.
- t Стьюдента при сильно различающихся дисперсиях — используйте Уэлча (`equal_var=False`, `T.TEST(…, 3)`).
- Независимый тест на парных данных (или наоборот).
- Тестирование платежей, когда единица — кредит: строки, не являющиеся независимыми, раздувают z.
- Шапиро на 50 000 строк, p ≈ 0, «значит, t-критерий мне нельзя» — ЦПТ заботится о n, QQ-график — о форме.
- Значимый результат без размера или громко звучащий RR без интервала (1.63, но 1.04–2.56).
- Тест между смешанными группами (канал = продукт), выданный за эффект канала.
- p-значение, напечатанное как `0.000` — пишите p < 0.001 и приводите рядом эффект.
