### Где работает ваш код — эта страница и Jupyter :id=where-your-code-runs--this-page-and-jupyter

**Что это.** У каждого блока Python на этой странице есть кнопка **▶ Run**. Первый запуск загружает Python в ваш браузер — около 15 МБ, один раз, потом из кэша — вместе с pandas, NumPy и matplotlib; дальше блок выполняется примерно за секунду. **Ноутбук** (*notebook*) — то же самое, сохранённое в один файл `.ipynb`: список **ячеек** с кодом или текстом, которые выполняются сверху вниз. **Jupyter** — программа, которая открывает ноутбуки; домашнее задание — это ноутбук.

**Как пишется.** Три правила страницы и три клавиши Jupyter:

- **Блоки делят одну память в том порядке, в котором вы их запускаете.** Имя, созданное в одном блоке, есть и в следующем — если вы его запустили.

### Значения и типы — int, float, str, bool, None :id=values-and-types--int-float-str-bool-none

**Что это.** У каждого значения в Python есть **тип** (*type*). Тип решает, что можно делать со значением: сложить два числа можно, а число и кусок текста — нельзя. `type(x)` называет тип.

**Как пишется.**

```python
type(31_150_000), type(0.30), type("Consumer loan"), type(True), type(None)
```

| значение | тип | что это |
|---|---|---|
| `31_150_000` | `int` | целое число; подчёркивания — только для глаз |
| `0.30` | `float` | число с десятичной точкой |
| `"Consumer loan"` | `str` | текст (*строка*) в одинарных или двойных кавычках |
| `True` / `False` | `bool` | да или нет, с заглавной буквы |
| `None` | `NoneType` | «нет значения» — NULL в Python |
| `"31150000"` | `str` | **текст, похожий на число** — то, что даёт CSV |

Блок показывает пять типов — `int`, `float`, `str`, `bool`, `NoneType` — по одному на значение, в порядке записи.

`int("42")` превращает текст в целое число, `float("3.12")` — в дробное, `str(42)` — число в текст.

**Когда применять.**
- Перед любой арифметикой с данными из файла: этот столбец — число или текст?
- Когда ошибка говорит `TypeError` — два значения несовместимых типов.

> ⚠️ **Осторожно.** `"31150000"` в кавычках — это текст. `"31150000" * 2` не удваивает его, а повторяет текст: `"3115000031150000"`. Сначала преобразуйте: `int("31150000") * 2` → `62300000`.

### Переменные — имя для значения :id=variables--a-name-for-a-value

**Что это.** **Переменная** (*variable*) — имя, которое указывает на значение. `=` даёт имени значение. Следующие строки используют имя вместо значения.

**Как пишется.**

```python
customer = "Gulbahor Sobirova"  # имя = значение
principal = 31_150_000
status = "active"
# новое значение для того же имени — "active" больше нет
status = "closed"
print(customer, principal, status)
```

```text
Gulbahor Sobirova 31150000 closed
```

Строка печатает `closed`, а не `active`: имя хранит только последнее значение.

Правила имён: буквы, цифры и `_`, не с цифры в начале; по привычке `snake_case` (`annual_rate`, а не `AnnualRate`); заглавные и строчные различаются (`Status` — другое имя). `=` присваивает значение; `==` спрашивает «равны ли они?» и отвечает `True` или `False`.

**Когда применять.**
- Для каждого значения, которое понадобится дважды: ставка, путь к файлу, дата отчёта.
- Чтобы дать числу смысл: `AS_OF`, `principal`, `late_count` читаются лучше, чем `2026-10-01`, `31150000`, `399`.

> ⚠️ **Осторожно.** `NameError: name 'principal' is not defined` значит, что строка, создающая имя, не выполнялась — в этом браузере или в этом ядре. Сначала запустите блок, который его определяет.

### Строки и f-строки — текст и числа внутри текста :id=strings-and-f-strings--text-and-numbers-inside-text

**Что это.** **Строка** (*string*) — это текст. **Методы** строки возвращают очищенную или изменённую копию: `.strip()` убирает пробелы по краям, `.lower()` / `.upper()` / `.title()` меняют регистр, `.replace(a, b)` заменяет текст, `.startswith(x)` проверяет начало. `s[:7]` берёт первые семь символов. **f-строка** (*f-string*) — `f"…{name}…"` — вставляет значения в текст.

**Как пишется.**

```python
method = "  Bank Transfer "
# 'bank transfer' — LOWER(TRIM()) с недели 2
clean = method.strip().lower()
print(clean.replace("bank transfer", "transfer"))
day = "2025-03-28"
print(day[:7], len(day))              # месяц и длина текста
status = "approved_not_disbursed"
print(status.startswith("approved"))  # шаблон "approved*" с недели 4
outstanding = 208_723_504_430
print(f"Outstanding: {outstanding:,} soum = {outstanding / 1e9:.1f} bn; PAR30 {0.0312:.2%}")
```

```output
transfer
2025-03 10
True
Outstanding: 208,723,504,430 soum = 208.7 bn; PAR30 3.12%
```

Способ оплаты превращается в `transfer`, из даты получается месяц `2025-03` (всего 10 символов), а одна f-строка пишет 208.7 млрд с разделителями тысяч и процент.

Часть после двоеточия внутри `{ }` — это **спецификация формата**: числовой формат Excel в другом написании:

| спецификация | значение | результат |
|---|---|---|
| `:,` | `208723504430` | `208,723,504,430` |
| `:.1f` | `208.7235` | `208.7` |
| `:.2%` | `0.0312` | `3.12%` |
| `:>8` | `"app"` | `"     app"` — по правому краю в 8 символах (`<` — по левому) |

**Когда применять.**
- Чистка текстовых столбцов: пробелы, регистр, написания (TRIM / PROPER / SUBSTITUTE с недели 4).
- Вырезать часть даты, записанной текстом: `applied_at[:7]` — это месяц.
- Вывод результата для человека: разделители, один знак после запятой, знак процента.

> ⚠️ **Осторожно.** Строка никогда не меняется на месте. `method.strip()` *возвращает* чистую копию, а `method` остаётся прежним. Сохраните результат: `method = method.strip()`.

### Числа и арифметика — операторы и округление :id=numbers-and-arithmetic--operators-and-rounding

**Что это.** Python считает через `+ - * /` и ещё три оператора: `//` (целочисленное деление), `%` (остаток) и `**` (степень). `round(x, n)` округляет до `n` знаков после запятой; отрицательное `n` округляет до десятков, сотен…

**Как пишется.**

```python
principal = 31_150_000          # кредит 1
annual_rate = 0.30
# проценты за 1-й месяц: годовые проценты на остаток ÷ 12
interest_1 = principal * annual_rate / 12
term = 24
print(interest_1)
print(term // 12, term % 12)    # целые годы, оставшиеся месяцы
print(round(1_741_684.35, -2))  # до ближайших 100 сумов
# месячная ставка — посмотрите на последние цифры
print(annual_rate / 12, round(annual_rate / 12, 4))
```

```text
778750.0
2 0
1741700.0
0.024999999999999998 0.025
```

Проценты за 1-й месяц — 778 750 сумов, ровно `interest_due` первой строки кредита 1 в `installments`. 24 месяца — это 2 целых года и 0 месяцев сверх того, а платёж 1 741 684.35 округляется до 1 741 700. Месячная ставка печатается как 0.024999999999999998 — ловушка ниже.

| оператор | пример | результат |
|---|---|---|
| `/` | `7 / 2` | `3.5` — всегда float |
| `//` | `7 // 2` | `3` — целая часть |
| `%` | `7 % 2` | `1` — остаток |
| `**` | `1.025 ** 2` | `1.050625` — степень |
| `round(x, 1)` | `round(58.23, 1)` | `58.2` |
| `round(x, -2)` | `round(1741684.35, -2)` | `1741700.0` |

Скобки работают как в школе: `100 * approved / total` и `(1 + r) ** -term` читаются так, как вы ожидаете. `abs(-5)` — это 5; `min(a, b)` и `max(a, b)` выбирают одно из двух.

**Когда применять.**
- Каждая ставка, доля и платёж: `100 * part / whole`.
- `round` — для вывода или там, где округляет сам бизнес (Nur Finance округляет платежи до 100 сумов).

> ⚠️ **Осторожно.** float хранится в двоичном виде, поэтому `0.30 / 12` получается `0.024999999999999998`, а не `0.025`. Ошибка крошечная, но `0.30 / 12 == 0.025` даёт `False`. Округляйте для вывода (`round(x, 4)`, `f"{x:.4f}"`) и никогда не сравнивайте два float через `==`. И `int(2.9)` — это `2`: `int()` отбрасывает дробную часть; когда нужно округление, пишите `round()`.

### Списки — упорядоченный столбец значений :id=lists--an-ordered-column-of-values

**Кортеж** (*tuple*) похож на список в круглых скобках, но после создания его нельзя изменить:

| | список `[ ]` | кортеж `( )` |
|---|---|---|
| можно менять | да: `append`, `x[0] = …` | нет |
| используется для | столбца значений | фиксированной пары или строки: `("Tashkent Central", 1001)` |

**Когда применять.**
- Столбец значений, который нужно сложить, посчитать, отсортировать (`sorted(x)`) или пройти циклом.
- Список меток в фиксированном порядке — корзины, месяцы, продукты.

> ⚠️ **Осторожно.** Позиции начинаются с 0, поэтому пятое значение — `x[4]`, а `x[5]` в списке из пяти значений — это `IndexError: list index out of range`. Срез `x[a:b]` останавливается перед `b`.

### if / elif / else — выбор по условию :id=if--elif--else--choose-by-a-condition

**Что это.** `if` выполняет блок, только когда условие равно `True`. `elif` («иначе если») проверяет следующее условие; `else` ловит всё остальное. Побеждает **первая** истинная ветка; остальные пропускаются. Это `CASE WHEN` с недели 2 и вложенный `IF` с недели 4.

**Как пишется.**

```python
dpd = 45

    bucket = "0"          # … четыре пробела отмечают, что к нему относится
elif dpd <= 30:
    bucket = "1-30"
elif dpd <= 60:
    bucket = "31-60"
elif dpd <= 90:
    bucket = "61-90"
else:
    bucket = "90+"
print(bucket)
```

```text
31-60
```

|---|---|---|---|---|---|---|---|---|
| корзина | 0 | 1-30 | 1-30 | 31-60 | 31-60 | 61-90 | 90+ | 90+ |

Сравнения: `==` равно, `!=` не равно, `<`, `<=`, `>`, `>=`, `in` (внутри списка или текста). Условия соединяют через `and`, `or`, `not`: `if status == "active" and dpd > 0:`.

**Когда применять.**

### Циклы for — один раз на элемент :id=for-loops--once-per-element

**Что это.** **Цикл for** (*for loop*) выполняет свой блок один раз для каждого элемента списка (или ключей словаря, или строк файла). Внутри блока переменная цикла — текущий элемент.

### Списковые включения — цикл for, который строит список :id=list-comprehensions--a-for-loop-that-builds-a-list

**Что это.** **Списковое включение** (*list comprehension*) — это `for`, который строит список в одну строку: `[выражение for элемент in элементы if условие]`. Читайте с середины: *для каждого элемента, если условие выполняется, взять выражение*.

**Как пишется.**

```python
dpds = [0, 7, 30, 31, 45, 90, 91, 919]
late = [d for d in dpds if d > 0]              # WHERE dpd > 0
doubled = [d * 2 for d in dpds]                # выражение для каждого элемента
print(late, len(late))
print(sum(1 for d in dpds if d > 90))          # COUNT с условием
```

```text
[7, 30, 31, 45, 90, 91, 919] 7
2
```

Семь из восьми значений — просрочка; два больше 90 дней. Завтра тот же фильтр в pandas будет булевой маской.

| SQL | включение |
|---|---|
| `SELECT dpd … WHERE dpd > 0` | `[d for d in dpds if d > 0]` |
| `SELECT dpd * 2` | `[d * 2 for d in dpds]` |
| `SELECT COUNT(*) … WHERE dpd > 90` | `sum(1 for d in dpds if d > 90)` |

**Когда применять.**
- Отфильтрованная или преобразованная копия списка: просроченные, суммы в виде `int`.
- Подсчёт с условием в одну строку.

> ⚠️ **Осторожно.** Включение, которое делает три вещи сразу, трудно читать. Когда в строке больше одного условия и одного выражения, напишите обычный цикл `for`.

### Функции — def, параметры, return :id=functions--def-parameters-return

**Что это.** **Функция** (*function*) — именованный шаг, который можно повторять. Она принимает входные данные (**параметры**, *parameters*), делает свою работу и возвращает один результат через `return`. Её пишут один раз через `def` и **вызывают** сколько угодно.

**Как пишется.**

```python
def approval_rate(approved, total, decimals=1):
    # docstring: что делает функция — для следующего читателя
    """Approval rate in percent."""
    if total == 0:
        # никогда не делим на ноль; None — «нет ответа»
        return None
    return round(100 * approved / total, decimals)

def label(dpd):
    """The DPD bucket of a number of days past due."""
    if dpd <= 0: return "0"
    elif dpd <= 30: return "1-30"
    elif dpd <= 60: return "31-60"
    elif dpd <= 90: return "61-90"
    else: return "90+"

print(approval_rate(2915, 5006), approval_rate(2915, 5006, 2), approval_rate(0, 0))
print(label(30), label(91))
```

| вызов | возвращает |
|---|---|
| `approval_rate(2915, 5006)` | `58.2` |
| `approval_rate(2915, 5006, 2)` | `58.23` — задан `decimals` |
| `approval_rate(0, 0)` | `None` |
| `label(30)`, `label(91)` | `'1-30'`, `'90+'` |

Канал app одобрил 2 915 из 5 006 заявок: 58.2 %, или 58.23 с двумя знаками. Канал без заявок получает `None` вместо падения.

`decimals=1` — **значение по умолчанию**: параметр становится необязательным. Короткий `if` помещается в одну строку (`if dpd <= 0: return "0"`), когда его блок — одна строка.

| `return` | `print` |
|---|---|
| возвращает значение — его можно сохранить, проверить, использовать снова | только показывает его на экране |
| `x = approval_rate(2915, 5006)` хранит 58.2 | `x = print(58.2)` хранит `None` |
| `assert approval_rate(2915, 5006) == 58.2` может это проверить | проверять нечего |

**Когда применять.**
- Любой шаг, который вы делаете дважды: метка корзины, ставка, аннуитетный платёж.
- Любое число, которое пойдёт в отчёт: положите его в функцию, затем проверьте функцию через `assert` (HW 5.1).

> ⚠️ **Осторожно.** Функция без `return` возвращает `None`. Функция, которая печатает ответ через `print`, выглядит правильно на экране и бесполезна для следующей строки кода.

### Чтение CSV через модуль csv :id=reading-a-csv-with-the-csv-module

**Что это.** `csv.DictReader` читает CSV-файл строка за строкой. Каждая строка становится **словарём**, ключи которого — строка заголовка. `list(...)` собирает все строки в список — список словарей, по одному на строку.

```python
print(rows[0]["channel"], rows[0]["status"], rows[0]["requested_amount"], type(rows[0]["requested_amount"]))
```

| `"product"` | `"Auto loan"` | `"Consumer loan"` |

`with open(...) as f:` открывает файл и закрывает его, когда блок заканчивается. `newline=""` убирает пустые строки в Windows; `encoding="utf-8"` правильно читает все буквы. Пустая ячейка приходит пустой строкой `""` — у 388 заявок `credit_score == ""`.

**Когда применять.**

### Ошибки — как читать трассировку, и try/except :id=errors--how-to-read-a-traceback-and-tryexcept

**Что это.** Когда Python не может выполнить строку, он останавливается и печатает **трассировку** (*traceback*): вызовы, которые привели к ошибке, новейший внизу, а на **последней строке** — тип ошибки и сообщение. `try: … except SomeError: …` ловит ожидаемую ошибку и вместо неё делает что-то разумное.

**Как пишется.** Этот блок падает намеренно — запустите его и прочитайте сначала нижнюю строку:

```python
def approval_rate(approved, total):
    return round(100 * approved / total, 1)

approval_rate(0, 0)          # канал без заявок
```

```output
Traceback (most recent call last):
  Cell In[7], line 4
    approval_rate(0, 0)
  Cell In[7], line 2, in approval_rate
    return round(100 * approved / total, 1)
↑ строка ВАШЕГО кода, где всё сломалось
ZeroDivisionError: division by zero
↑ ПОСЛЕДНЯЯ строка: что пошло не так —
  читайте её первой
```

Последняя строка называет ошибку: деление на итог, равный нулю. Строка над ней указывает на `return round(100 * approved / total, 1)` внутри `approval_rate`.

Поймать ожидаемую ошибку:

```python
def safe_int(text):
    try:
        return int(text)
    except ValueError:            # int("") или int("n/a") — не число
        return None

print(safe_int("658"), safe_int(""), safe_int("n/a"))
```

```text
658 None None
```

Настоящий балл становится числом 658; пустое значение и мусор становятся `None` вместо остановки всего запуска.

| ошибка | обычно значит | исправление |
|---|---|---|
| `NameError` | имя не определено — или определено в блоке, который вы не запустили | запустите блок выше |
| `TypeError` | смешаны текст и число: `"42" + 1` | преобразуйте через `int()` / `float()` |
| `KeyError` | ключа словаря или столбца не существует | сверьте написание с заголовком |
| `IndexError` | позиция за концом списка | позиции начинаются с 0 |
| `ValueError` | тип верный, значение — нет: `int("n/a")` | сначала проверьте значение или `try/except` |
| `ZeroDivisionError` | деление на 0 | сначала проверьте итог |
| `FileNotFoundError` | неверный путь для места, где работает Python | проверьте папку |
| `SyntaxError` / `IndentationError` | пропущены `:` или скобка; не те пробелы | смотрите *прямо перед* стрелкой |

**Когда применять.**
- При каждой ошибке: прочитайте последнюю строку, затем строку вашего кода, на которую она указывает.
- `try/except` — только для ожидаемых ошибок, которые вы знаете, как обработать: пустой балл, плохая дата.

> ⚠️ **Осторожно.** Голый `except:` без имени ошибки прячет любую ошибку, опечатки тоже. Называйте ожидаемую ошибку: `except ValueError:`.

Один вопрос, все инструменты дня: *какая доля кредитов просрочена (`dpd > 0`) в каждом продукте?* Прочитать файл (**csv**), пройти строки (**for**), преобразовать текст (**типы**), проверить условие (**if**), посчитать по продуктам в двух **словарях**, вычислить долю **функцией**, вывести **f-строкой**.

```python
    """part as a percent of whole, two decimals."""
    return round(100 * part / whole, 2) if whole else None

with open("../excel/loans_status.csv", newline="", encoding="utf-8") as f:
```

## 2. Разбор примера — доля одобрений по каналам от Жасура, в циклах (15 мин) :id=_2-worked-example-jasur39s-approval-rate-by-channel-in-loops-15-min

Задача: доля одобрений = одобренные ÷ заявки, по каналам. Каждый шаг использует одно понятие из раздела 1 — в том порядке, в котором вы их учили.

1. **Шаг 1 — чтение CSV** (`csv.DictReader`). Одна строка = одна заявка; 14 000 строк; каждое значение — текст.

```python
import csv
```

## 6. Уголок компании <span class="badge company">Формула аннуитета</span> :id=6-company-corner-the-annuity-formula

Каждый платёж в `installments` (92 193 строки) был получен по одной формуле. **Аннуитетный** (*annuity*) кредит платится одной и той же суммой каждый месяц; внутри этой суммы доля **процентов** уменьшается, а доля **основного долга** растёт по мере снижения остатка:

```
payment = P × r / (1 − (1 + r)^−n)

P = основной долг
r = annual_rate / 12
n = срок в месяцах
```

Nur Finance округляет платёж до ближайших **100 сум** (`round(x, -2)`), а BNPL с нулевой ставкой просто делит `P / n`. На Python:

```python
def annuity(principal, annual_rate, term):
    r = annual_rate / 12
    pay = principal / term if r == 0 else principal * r / (1 - (1 + r) ** -term)
    return int(round(pay, -2))

annuity(31_150_000, 0.30, 24)     # 1741700 — кредит 1
```
