# Инструменты на работе (по желанию)

<span class="badge">Для этого курса не требуется</span>

Всё в этом курсе работает на его сайте: SQL-окна, [SQL-песочница](playground.md), панель «База данных», окошки сдачи работ. **Для SQL вам никогда не придётся ничего устанавливать.**

Эта страница — на потом: для работы или собеседования, где спросят *«какими инструментами вы пользовались?»*. Банки работают на SQL Server или PostgreSQL, а запросы пишут в SSMS, DBeaver или DataGrip; SQL там тот же, что и здесь. Сделайте что-нибудь из этого в свободный вечер, если захотите.

## SQL Server Express + SSMS (чем пользуется большинство банков) :id=sql-server-express-ssms-what-most-banks-use

1. Скачайте **SQL Server 2022 Express** (бесплатно): https://www.microsoft.com/en-us/sql-server/sql-server-downloads → *Express* → запустите установщик → **Basic**.
2. Скачайте **SQL Server Management Studio (SSMS)**: https://aka.ms/ssmsfullsetup → установите → откройте → *Connect* с именем сервера, которое показал установщик Express (обычно `localhost\SQLEXPRESS`), Windows Authentication.
3. В SSMS: *File → New → Query*. Вставьте и выполните (F5):

```sql
CREATE DATABASE nur;
GO
USE nur;
GO
```

4. Откройте файл `data/sql/sqlserver.sql` из папки курса (*File → Open*). Сначала выполните блок **CREATE TABLE** (выделите его, F5), затем строки **BULK INSERT**. Если `BULK INSERT` ругается на путь, исправьте путь на тот, где лежит ваша папка курса.
5. Проверьте:

```sql
SELECT COUNT(*) AS loans FROM loans;        -- ожидаем 7828
SELECT COUNT(*) AS customers FROM customers; -- ожидаем 6040
```

▶ Бараа показывает такую же установку на [0:22:33](https://youtu.be/SSKVgrwhzus?t=1353&end=2041).


## SQLite с DB Browser (10 минут) :id=sqlite-with-db-browser-10-minutes

1. Скачайте **DB Browser for SQLite**: https://sqlitebrowser.org/dl/ → установщик для Windows → установите.
2. *Open Database* → выберите `data/raw/nur.db` в папке курса. Все 11 таблиц уже там.
3. Вкладка *Execute SQL* → вставьте → Ctrl+Enter:

```sql
SELECT COUNT(*) AS loans FROM loans;  -- ожидаем 7828
```

Различия, с которыми вы столкнётесь: там, где SQL Server пишет `TOP 10`, SQLite пишет `LIMIT 10`; даты — это текст в формате `YYYY-MM-DD`. Страницы всегда показывают оба варианта, когда они отличаются.

## GitHub Desktop — храним работы в репозитории :id=github-desktop-keeping-your-work-in-a-repository

Так делают аналитики на работе: в каждом домашнем задании указана папка вроде `submissions/week-01/day-1/`. Положите туда свои файлы и сделайте push.

### Настройка один раз (15 мин) :id=one-time-setup-15-min

1. Создайте бесплатный аккаунт на https://github.com, если его нет, и отправьте свой логин ментору; вас пригласят в репозиторий курса (примите письмо от GitHub).
2. Установите **GitHub Desktop**: https://desktop.github.com → войдите → *Clone a repository* → выберите репозиторий курса → выберите папку на компьютере.
3. Откройте папку. `docs/` — это курс; `submissions/` — ваша.

### Проверьте перед отправкой :id=check-before-you-send

Большинство домашних заданий можно сначала проверить на своём компьютере. В терминале, в папке курса:

```bash
python scripts/check.py list
```

показывает, какие домашние задания можно проверить, а, например,

```bash
python scripts/check.py hw1.2
```

запускает ваш `bekzod.sql` на данных Nur Finance и отвечает по каждому заданию: **OK** или **NO** с причиной (запрос не выполнился, число не совпало с ожидаемым, не сходится число строк). Правильный ответ он никогда не показывает, поэтому красная строка значит: вернитесь и подумайте, а не подсматривайте. Пишите на SQLite или SQL Server — подойдёт и то, и другое. Файлы Excel проверяются по ячейкам, ноутбуки запускаются с самого начала вместе со всеми assert, а скрипты Python запускаются, и выходные файлы пересчитываются.

Всё зелёное? Отправляйте. Ментор всё равно читает ваши запросы, комментарии и текст: проверка подтверждает цифры, а ментор оценивает мышление.

### Каждый раз :id=each-time

1. Создайте папку, которую называет страница (например, `submissions/week-01/day-2/`).
2. Сохраните туда свои файлы. Используйте имена, которые просит страница. SQL — в `.sql`, текст — в `.md`, скриншоты — в `.png`, ноутбуки — в `.ipynb`, книги Excel — в `.xlsx`.
3. В GitHub Desktop: напишите однострочное описание (например, `HW 1.2 — 10 queries for Bekzod`) → **Commit to main** → **Push origin**.
4. В боте курса нажмите **📤 Hand in homework**, выберите домашнее задание, затем **I pushed it to GitHub instead**. Бот проверит, что ваши файлы действительно есть на GitHub (если какого-то нет, он скажет, какого), и сообщит ментору в теме 📤 Homework.

Не получается разобраться с GitHub Desktop? Используйте вместо этого окошко на странице урока — оно засчитывается так же. Отправка файлов — часть работы.
