# Analytics Learning

An 8-week Data Analysis course, built for one learner heading to an analyst role in lending.

- **The course:** `docs/` — one Markdown page per day, served with Docsify. Open locally with `python -m http.server 3000 -d docs` → http://localhost:3000, or via GitHub Pages.
- **Her homework:** `submissions/week-NN/day-D/`; feedback lands as `FEEDBACK.md` in the same folder.
- **Sources** (lecture decks, notebooks, recordings; 767 MB, not in git): `sources/` — map in `docs/sources.md`.
