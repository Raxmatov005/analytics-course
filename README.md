# Analytics Learning — your 8-week course

From zero to analyst in eight weeks, on the data of Nur Finance, a lending company.

- **Read the course here:** https://raxmatov005.github.io/analytics-course/ — start with *Practice day*, then *Day 0*.
- **Your homework** goes into `submissions/week-NN/day-D/` (the page names the exact folder); your feedback arrives as `FEEDBACK.md` in the same folder. How: `docs/homework/how-to-submit.md`.
- **Check your work first:** `python scripts/check.py list` shows what can be checked; `python scripts/check.py hw1.2` checks one homework.
- **The data:** `data/raw/nur.db` (open it with DB Browser for SQLite) and the CSV files next to it; extracts for Excel, Python and Power BI in `data/excel`, `data/python`, `data/powerbi`, `data/ab`.
